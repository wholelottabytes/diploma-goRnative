# ОПИСАНИЕ РАЗРАБАТЫВАЕМОГО РЕШЕНИЯ

Разрабатываемое решение представляет собой мобильное приложение, позволяющее музыкальным продюсерам публиковать, организовывать и продавать свои авторские биты, а покупателям — находить, прослушивать и приобретать музыкальный контент для своих проектов.

Ключевая идея платформы заключается в том, что музыкальный контент становится доступным и защищённым не тогда, когда он просто загружен на хостинг, а тогда, когда он проходит проверку на уникальность, имеет прозрачную систему лицензирования и встроенные инструменты для взаимодействия между автором и покупателем. Этот принцип лежит в основе современной цифровой дистрибуции музыки — системы, где каждый трек имеет уникальный аудиоотпечаток, метаданные и историю транзакций.

Современные платформы для продажи битов делятся на два принципиальных класса. Первый — универсальные стриминговые сервисы (BeatStars, Airbit), предоставляющие широкий функционал для монетизации, но требующие ежемесячной подписки и взимающие комиссию с каждой продажи. Они мощные, но дорогие для начинающих продюсеров. Второй класс — социальные платформы для музыкантов (SoundCloud, Bandcamp), ориентированные на продвижение и стриминг, но не предоставляющие специализированных инструментов для продажи битов с лицензиями. Именно такой подход — сочетание социальной платформы с маркетплейсом — стал стандартом в индустрии и лёг в основу успешных сервисов вроде BeatStars.

Несмотря на распространённость подобных платформ, большинство решений либо требуют ежемесячной оплаты (BeatStars от $9.99/мес), либо взимают высокую комиссию с продаж (Airbit до 30%), либо не предоставляют мобильной версии для работы в пути. Популярные стриминговые платформы вроде SoundCloud, в свою очередь, не имеют встроенной системы продажи лицензий. Таким образом, существует практически незакрытая ниша: бесплатное мобильное приложение с минимальной комиссией, сочетающее загрузку битов с системой аудиофингерпринтинга для защиты от плагиата и встроенным редактором для управления каталогом.

Разрабатываемое мобильное приложение призвано заполнить эту нишу, предлагая пользователям удобный инструмент для публикации и продажи авторских битов с наглядной статистикой прослушиваний, системой оценок и модерацией сообщества, доступный из любой точки мира без ежемесячных платежей.

Среди аналогов были выделены следующие:
– BeatStars;
– Airbit;
– SoundCloud;
– Bandcamp.
