Привет!

Я задокументировал проблемы, с которыми я столкнулся при запуске React Native приложения, и как я их решил.

**Проблема 1: Сбой подключения к Metro Bundler**

Приложение на устройстве не могло подключиться к Metro Bundler, который работает на компьютере. Причина в том, что приложение пыталось подключиться к `localhost:8081`. Когда приложение запущено на устройстве, `localhost` указывает на само устройство, а не на компьютер, где запущен Metro Bundler. Это приводило к тому, что приложение не могло загрузить JavaScript-код и другие ресурсы.

**Решение 1: Использование `adb reverse`**

Я использовал команду `adb reverse tcp:8081 tcp:8081`. Эта команда "пробрасывает" порт 8081 с устройства на порт 8081 компьютера. Таким образом, когда приложение на устройстве обращается к `localhost:8081`, запрос на самом деле уходит на компьютер, где его успешно обрабатывает Metro Bundler.

**Проблема 2: Падение приложения с нативной ошибкой (FATAL EXCEPTION)**

Приложение падало с ошибкой `FATAL EXCEPTION` в нативном коде (`libreactnative.so`). Скорее всего, это было следствием первой проблемы. Так как приложение не могло загрузить JavaScript-бандл, оно завершалось с критической ошибкой.

**Решение 2:**

Решение первой проблемы (настройка `adb reverse`) автоматически решило и эту проблему, так как приложение смогло успешно загрузить все необходимые ресурсы и запуститься.

**Как запустить приложение в будущем:**

1.  Перейдите в директорию `rnat`:
    ```bash
    cd rnat
    ```
2.  Запустите Metro Bundler в одном терминале:
    ```bash
    npm start
    ```
3.  Откройте второй терминал и запустите приложение на устройстве:
    ```bash
    npm run android
    ```
4.  Если вы снова столкнетесь с проблемами подключения (например, приложение показывает белый экран или падает при запуске), выполните команду:
    ```bash
    adb reverse tcp:8081 tcp:8081
    ```

Сейчас Metro Bundler запущен в фоновом режиме. Если вы захотите его остановить, вам нужно будет найти и завершить соответствующий процесс.

Надеюсь, это поможет в будущем!
