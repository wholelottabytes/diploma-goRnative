# АНАЛИЗ МОБИЛЬНЫХ ПРИЛОЖЕНИЙ-АНАЛОГОВ

## BeatStars Mobile App

BeatStars Mobile — мобильное приложение для iOS и Android, предоставляющее продюсерам возможность управлять своим каталогом битов, отслеживать продажи и взаимодействовать с покупателями непосредственно со смартфона. Приложение было выпущено в 2015 году как дополнение к веб-платформе и на сегодняшний день является одним из наиболее функциональных мобильных решений для продажи музыкального контента.

Приложение доступно для бесплатной загрузки в App Store и Google Play. После установки пользователю предлагается войти в существующий аккаунт BeatStars или зарегистрировать новый. Важно отметить, что для полноценной работы приложения требуется активное подключение к интернету — офлайн-режим не предусмотрен. Стартовый экран приложения BeatStars показан на рисунке 1.1.

**Рисунок 1.1 – Экран авторизации BeatStars Mobile**

Как было сказано ранее, идея мобильного приложения BeatStars лежит в возможности предоставления продюсерам доступа к своему бизнесу в любом месте. Пользователь может загружать новые биты прямо с телефона, отвечать на сообщения от покупателей, отслеживать статистику продаж в реальном времени и получать уведомления о новых покупках. Мобильность платформы является одной из ключевых особенностей данного сервиса, позволяя продюсерам работать без привязки к компьютеру.

После успешной авторизации приложение открывает пользователю главный экран с дашбордом. Интерфейс приложения представлен на рисунке 1.2.

**Рисунок 1.2 – Главный экран (Dashboard) BeatStars Mobile**

Интерфейс приложения построен по принципу нижней навигационной панели с пятью основными разделами: «Home», «Explore», «Upload», «Messages», «Profile». Такое расположение соответствует стандартам мобильных приложений и обеспечивает удобную навигацию одной рукой. В центральной части главного экрана отображается сводная статистика: количество прослушиваний за неделю, новые продажи, доход за текущий месяц и топ битов по популярности.

Важно учесть, что мобильное приложение не предоставляет полного функционала веб-версии. Например, настройка типов лицензий и редактирование профиля доступны только через веб-интерфейс. Однако базовые функции — загрузка бита, просмотр статистики, общение с покупателями — полностью адаптированы для мобильного использования.

На рисунке 1.3 продемонстрирован процесс загрузки нового бита через мобильное приложение: пользователь выбирает аудиофайл из памяти устройства, вводит название, жанр, BPM, тональность, устанавливает цену и выбирает обложку. После публикации бит автоматически становится доступным для покупки в каталоге.

**Рисунок 1.3 – Процесс загрузки бита в BeatStars Mobile**

Помимо загрузки битов, приложение BeatStars позволяет организовывать каталог с помощью фильтров и сортировки. Для этого присутствует целый ряд инструментов: фильтрация по жанру, статусу (опубликовано/черновик), дате загрузки, количеству продаж.

Раздел «Explore» представляет собой ленту рекомендованных битов от других продюсеров. Пользователь может прослушивать композиции, добавлять их в избранное и переходить в профили других продюсеров. На рисунке 1.4 представлена карточка бита в разделе Explore с указанием названия, имени продюсера, цены и кнопки для прослушивания.

**Рисунок 1.4 – Карточка бита в разделе Explore**

Также приложение даёт возможность пользователю отслеживать статистику в реальном времени. Раздел «Analytics» показывает количество прослушиваний, скачиваний и покупок за выбранный период (день, неделя, месяц, год). Создание отчёта по продажам показано на рисунке 1.5.

**Рисунок 1.5 – Статистика продаж**

Взаимодействие со статистикой реализовано интуитивно: клик по любому биту открывает детальную аналитику по конкретной композиции — количество прослушиваний по источникам (прямые заходы, поиск, социальные сети), географию покупателей, динамику продаж по дням. Это обеспечивает глубокое понимание аудитории без необходимости использования сторонних инструментов аналитики.

Главное преимущество мобильной аналитики BeatStars заключается в возможности получения уведомлений о продажах мгновенно. При каждой покупке пользователь получает push-уведомление с указанием проданного бита, типа лицензии и суммы дохода. В отличие от веб-версии, где нужно самостоятельно проверять раздел «Продажи», мобильное приложение активно информирует продюсера о важных событиях. Система push-уведомлений показана на рисунке 1.6.

**Рисунок 1.6 – Push-уведомление о продаже**

Стоит учитывать, что BeatStars Mobile не является полностью автономным приложением. Для первичной настройки профиля, загрузки банковских реквизитов для выплат и настройки типов лицензий пользователю необходимо воспользоваться веб-версией. Однако для повседневного управления каталогом и отслеживания продаж мобильного приложения вполне достаточно.

Приложение предоставляет пользователю функцию «Direct Messages» для общения с покупателями. Для этого в нижней панели навигации выделен отдельный раздел «Messages». При нажатии на кнопку «Написать сообщение» открывается диалог с выбранным пользователем. Поскольку сервис подразумевает возможность обсуждения индивидуальных условий лицензии (эксклюзивные права, кастомные условия), данная функция является важной частью платформы. Встроенный мессенджер показан на рисунке 1.7.

**Рисунок 1.7 – Встроенный мессенджер**

Помимо стандартных сообщений, приложение поддерживает отправку приватных ссылок на биты (для предварительного прослушивания перед покупкой) и голосовые сообщения. Это соответствует философии «mobile-first», где пользователь может быстро ответить покупателю без необходимости открывать компьютер.

Особое внимание в мобильном приложении уделено разделу «Profile». Здесь пользователь может просмотреть свой публичный профиль (так, как его видят покупатели), отредактировать описание, добавить ссылки на социальные сети и управлять отображаемыми битами. На рисунке 1.8 показан экран профиля продюсера с информацией о количестве подписчиков, общих продажах и списком битов.

**Рисунок 1.8 – Профиль продюсера**

Таким образом, BeatStars Mobile представляет собой мощный инструмент для управления продажами битов со смартфона, оптимальный для продюсеров, которые хотят оставаться на связи с покупателями и отслеживать статистику в реальном времени, но менее подходящий для первичной настройки магазина и глубокой аналитики.

## Airbit Mobile App

Airbit Mobile — мобильное приложение для iOS и Android, разработанное компанией Airbit как дополнение к одноимённой веб-платформе для продажи битов и музыкальных лицензий. Приложение было запущено в 2016 году и ориентировано в первую очередь на быструю загрузку контента и мониторинг продаж. В отличие от BeatStars, Airbit делает акцент на минималистичном интерфейсе и скорости работы.

Приложение доступно для бесплатной загрузки в App Store и Google Play. После установки пользователю предлагается войти в существующий аккаунт Airbit или зарегистрировать новый. Важно отметить, что приложение требует обязательной привязки аккаунта PayPal или Stripe для получения выплат — без этого шага загрузка битов невозможна. Стартовый экран приложения Airbit показан на рисунке 1.9.

**Рисунок 1.9 – Экран авторизации Airbit Mobile**

Идея мобильного приложения Airbit лежит в возможности максимально упростить процесс загрузки и управления битами для продюсеров, которые работают в движении. Пользователь может загрузить новый бит за три шага: выбрать файл, указать название и цену, опубликовать. Такой подход отличается от BeatStars, где процесс загрузки требует заполнения множества полей (жанр, BPM, тональность, теги, обложка, несколько типов лицензий). Мобильность в Airbit означает «загрузил и забыл» — минимальные усилия для публикации контента.

После успешной авторизации приложение открывает пользователю библиотеку загруженных битов. Интерфейс приложения представлен на рисунке 1.10.

**Рисунок 1.10 – Библиотека битов Airbit Mobile**

Интерфейс приложения построен по принципу верхней навигационной панели с тремя основными разделами: «My Beats», «Analytics», «Settings». Нижняя часть экрана занята списком битов с краткой информацией (название, дата загрузки, количество продаж, доход). Такое расположение обеспечивает максимальную площадь для контента, но менее удобно для навигации одной рукой по сравнению с нижней панелью BeatStars.

Важно учесть, что мобильное приложение Airbit не предоставляет доступа к разделу «Explore» или ленте рекомендованных битов. Просмотр и покупка битов других продюсеров возможны только через веб-версию. Мобильное приложение ориентировано исключительно на управление собственным каталогом продюсера.

На рисунке 1.11 продемонстрирован процесс загрузки нового бита: пользователь нажимает кнопку «+» в правом верхнем углу, выбирает аудиофайл из памяти устройства, вводит название и цену. Дополнительные поля (жанр, BPM, описание) можно заполнить позже через веб-интерфейс. После публикации бит автоматически получает стандартную лицензию по умолчанию.

**Рисунок 1.11 – Процесс загрузки бита в Airbit Mobile**

Помимо загрузки битов, приложение Airbit позволяет отслеживать базовую статистику. Для этого предназначен раздел «Analytics», показывающий общий доход за выбранный период и количество проданных лицензий. На рисунке 1.12 представлена сводная статистика с графиком продаж по дням.

**Рисунок 1.12 – Статистика продаж Airbit**

Взаимодействие со статистикой реализовано упрощённо: пользователь может выбрать период (7 дней, 30 дней, 90 дней, всё время) и увидеть общий доход и количество продаж. Детальная аналитика по отдельным битам, география покупателей и источники трафика недоступны в мобильной версии — для этого необходимо использовать веб-интерфейс.

Главное преимущество мобильной аналитики Airbit заключается в простоте и скорости загрузки. В отличие от BeatStars, где загрузка бита требует заполнения 10+ полей, Airbit позволяет опубликовать композицию за 30 секунд. Это особенно удобно для продюсеров, которые хотят быстро загрузить черновик или демо-версию для последующего редактирования через веб-интерфейс.

Стоит учитывать, что Airbit Mobile не поддерживает встроенный мессенджер. Для общения с покупателями пользователю необходимо перейти на веб-версию или использовать сторонние средства связи (email, социальные сети). Это соответствует философии «minimalism», где приложение фокусируется на одной ключевой функции — быстрой загрузке контента.

Приложение предоставляет пользователю функцию «Quick Settings» для базовой настройки профиля. Для этого в разделе «Settings» можно изменить отображаемое имя, аватар и ссылку на профиль. Поскольку сервис подразумевает более глубокую кастомизацию через веб-интерфейс (баннеры, цвета, описание), данная функция является ограниченной. Настройки профиля показаны на рисунке 1.13.

**Рисунок 1.13 – Настройки профиля Airbit Mobile**

Помимо стандартных настроек, приложение поддерживает переключение между несколькими аккаунтами продюсера (для лейблов и команд). Это соответствует философии «multi-account», где пользователь может быстро переключаться между разными профилями без необходимости повторной авторизации.

Особое внимание в мобильном приложении уделено разделу «Notifications». Здесь пользователь может настроить типы push-уведомлений: новые продажи, новые сообщения, новые подписчики. На рисунке 1.14 показан экран настроек уведомлений с переключателями для каждого типа событий.

**Рисунок 1.14 – Настройки уведомлений**

Таким образом, Airbit Mobile представляет собой минималистичный инструмент для быстрой загрузки битов и отслеживания продаж, оптимальный для продюсеров, которые ценят скорость и простоту, но менее подходящий для глубокой аналитики и взаимодействия с покупателями.
